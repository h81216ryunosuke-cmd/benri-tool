JSON整形ツール（フォーマッター）

崩れたJSONを見やすく整形、または1行に圧縮します。構文エラーがあれば表示します。

入力したJSONはブラウザ内でのみ処理され、サーバーには送信されません。

よくある質問

「予期しないトークン」というエラーが出ます

JSONの構文（カンマの付け忘れ・付けすぎ、クォートの閉じ忘れ等）に誤りがある可能性が高いです。エラーメッセージに表示される位置周辺を確認してください。

シングルクォートで書いたJSONは読み込めますか？

JSONの仕様上、文字列はダブルクォート（"）で囲む必要があります。シングルクォート（'）で書かれたものはJavaScriptのオブジェクトリテラルとしては有効でも、正式なJSONとしてはエラーになります。
