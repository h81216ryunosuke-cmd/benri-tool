カラーコード変換（HEX/RGB/HSL）

いずれか1つの形式を入力すると、他の形式に自動変換してプレビュー表示します。

よくある質問

HEX・RGB・HSLはそれぞれ何に使いますか？

HEXはCSSやデザインツールで最も一般的な指定方法、RGBは光の三原色（赤・緑・青）による指定、HSLは色相・彩度・明度で直感的に色を調整したい時に便利です。

入力した色はどこかに保存されますか？

いいえ、変換処理はすべてブラウザ内で完結しており、サーバーに送信・保存されることはありません。
